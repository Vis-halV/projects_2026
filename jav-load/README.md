# jav-load

Standalone **Vite + React + TypeScript + Tailwind CSS** project that contains the **Shoji Loader** component (doors → petals → title reveal).

## Run

```bash
cd jav-load
npm install
npm run dev
```

## Use the component

- Component: `jav-load/src/components/ShojiLoader.tsx`
- Export: `jav-load/src/index.ts`
